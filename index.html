Getting Started

Each demo folder is self-contained with its own README, setup scripts, and agent configurations. Clone the repo and navigate to a demo to get started:

git clone https://github.com/solo-io/webinar-demos.git
cd webinar-demos/01-team-lead-agents
cat README.md
